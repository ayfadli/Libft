# 1337 (42 Network) Curriculum Projects

This repository contains projects from the 1337 School (42 Network) curriculum. Each project has its own directory with detailed documentation.

## Overview
The 1337 School curriculum is project-based and covers various aspects of computer science, from low-level programming to system administration. This repository is organized by project, with each folder containing the project's code and a comprehensive README.

## Projects

### 📚 C Projects

#### [libft](./libft)
The foundational C library project - the first project in the 1337 curriculum. Students create their own implementation of standard C library functions.

**Key Learnings**: String manipulation, memory management, character operations

#### [ft_printf](./ft_printf)
Recode of the printf() function from the C standard library.

**Key Learnings**: Variadic functions, format parsing, type conversions

### 🖥️ System Administration Projects

#### [Born2beRoot](./Born2beRoot)
Virtual machine setup and system administration fundamentals.

**Key Learnings**: Linux administration, LVM, SSH, UFW, security hardening

## Repository Structure

Each project directory contains:
- **README.md** - Comprehensive documentation including:
  - Project description and role in curriculum
  - Usage instructions
  - Build/compilation instructions (for C projects)
  - Configuration details (for SysAdmin projects)
- **Source code** - Project implementation files
- **Makefile** - Build automation (for C projects)
- **Configuration files** - Setup details (for SysAdmin projects)

## Getting Started

Navigate to any project directory to view its specific README with detailed instructions:

```bash
cd libft/          # For the Libft C library
cd ft_printf/      # For the printf implementation
cd Born2beRoot/    # For system administration project
```

## About 1337 School

1337 School (part of the 42 Network) is a tuition-free, peer-to-peer learning institution. The curriculum emphasizes:
- Self-learning and problem-solving
- Collaborative project work
- Real-world programming challenges
- No traditional teachers or lectures
